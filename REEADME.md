# Advanced Data Science Project

Predicting (NO2) concentrations using low-cost air quality sensors and machine learning.

## Dataset
Air quality sensor measurements from Rouen, France.

## Technologies
- Python
- Google Colab
- Pandas
- Scikit-learn
- Streamlit

## Project Objectives
- Explore and preprocess air quality data.
- Train and compare regression models.
- Evaluate prediction accuracy.
- Develop an interactive Streamlit dashboard.
